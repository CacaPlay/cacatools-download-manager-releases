# Soporte

Para reportar un fallo, abre un issue en este repositorio si Issues está
habilitado o contacta al propietario `@CacaPlay` mediante GitHub.

Incluye:

- versión de CacaTools y de Windows;
- pasos reproducibles;
- mensaje de error y hora aproximada;
- diagnóstico exportado desde Ajustes, si el programa lo ofrece.

No publiques contraseñas, cookies, tokens, claves privadas, URLs privadas ni
datos personales. Para una vulnerabilidad de seguridad usa las instrucciones
de [SECURITY.md](SECURITY.md), no un issue público.
