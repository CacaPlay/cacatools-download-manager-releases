# Seguridad

Si encuentras una vulnerabilidad, no la publiques en un issue. Envía un
reporte privado al propietario `@CacaPlay` mediante GitHub e incluye la
versión afectada, impacto y pasos mínimos para reproducirla.

Nunca compartas claves de firma, contraseñas, tokens, cookies o archivos de
usuario. Las descargas oficiales deben conservar la verificación de firma y
hash; no la desactives para probar un instalador.
