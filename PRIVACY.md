# Política de privacidad

CacaTools procesa localmente la URL, el título, la miniatura pública y los
metadatos visibles de las páginas HTTP/HTTPS para preparar una descarga. La
extensión solo envía una selección al escritorio cuando el usuario confirma la
acción desde su panel. Las descargas normales se capturan únicamente si el
usuario activa esa opción.

No se recopilan ni se envían cookies, contraseñas, encabezados de autorización,
tokens, historial, playlists personales, nombres de archivos ni telemetría.
La comunicación con la aplicación usa Chrome Native Messaging mediante un
proceso local. Solo se aceptan destinos `http` y `https`.

Para preguntas sobre privacidad, consulta [Soporte](SUPPORT.md). Esta política
describe la distribución oficial actual y puede cambiar junto con una nueva
versión publicada.
