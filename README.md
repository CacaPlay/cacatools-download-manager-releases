# Clear Download Manager — Legacy Update Bridge

This repository is a temporary compatibility channel for older Clear Download Manager installations. It is being phased out after the migration period and is not the primary project or download page.

## Current downloads and source

For the current installer, release notes, checksums, signatures and source code, visit the [main Clear Download Manager repository](https://github.com/CacaPlay/clear-download-manager). Its [latest release](https://github.com/CacaPlay/clear-download-manager/releases/latest) is the supported download location.

## Existing installations

Some older app versions use this repository to discover a migration update. This bridge will remain available during the transition; use the updater in the app when it offers the migration. The latest bridge release points to the 0.95.4 installer published in the main repository.
